# hush

a calm and quiet dark theme for code editors and terminal tools.

neovim: add `steelesh/hush` to your plugin manager and run `colorscheme hush`. vs code, intellij, ghostty, tmux, fzf, delta, bat, lazygit, yazi, starship, btop and lnav each have a file under [`themes/`](themes).

> made for my own setup. it may not cover your tools or plugins.
